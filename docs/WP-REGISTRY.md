# Реестр рабочих продуктов (РП)

> Один РП - одна папка `inbox/WP-N/` с карточкой `WP-N.md`. Название - существительное-результат, до 80 символов, без дат и служебных пометок. Новые РП заводит скилл `wp-new` после явного «да» владельца.
> Статусы: `pending` (принят, не начат), `in_progress`, `deferred` (отложен, условие пересмотра - в карточке), `done`.
