# Личные DPF

Здесь лежат фреймворки предметных областей, которые ведёт владелец базы (личные DPF по E.4): методы, полезные вне конкретного проекта и без данных компании. Проектные DPF живут в `dpf/` своего проекта, а не здесь (раздел 3 `AGENTS.md`).

Один фреймворк - один файл `<название>.md`, пока он компактный (E.4.DPF): заголовок и строка издания, оглавление, Readme с практическими входами, предисловие, паттерны по E.8, источники и условия обновления (E.11.PFP). Новый фреймворк начинается с семени и записи решения в `decisions/` (E.4.PFAD); статус «семя» снимается только после оценки E.21 и E.4.DPF.DA.
