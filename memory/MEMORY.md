# Память workbench

> Личная память владельца: факты о нём и его способе работы. Агент видит этот индекс во всех проектах с workbench (через `CLAUDE.local.md`), а в сессиях в самой базе - как память Claude Code. Файлы лежат рядом с индексом, в `memory/`. Одна запись = один факт: файл + одна строка здесь (`- [Название](файл.md) - зачем помнить`). Записывать только подтверждённое владельцем и только то, что меняет будущий выбор; факты о целевых проектах сюда не пишутся.
